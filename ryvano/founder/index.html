2. How to walk through it (17 screens, one decision each)

  1. Welcome, with a short plain explanation and a real-screen preview. open
  2. About you: optional nickname, age range, country (searchable), interests. open
  3. Get started demo, then Today, Train, Food, Money, Circle. Each has one small task, then a three-card "How useful?" sheet and, for tasks, "How was it?" (Easy / Okay / Difficult).
  4. Avatars (real Kit 9), More features (Recovery, Health, Calendar), Ideas not built (pick up to 3).
  5. Five closing questions, one per screen, then a single Send. After sending, the answers are recorded once; the only way to change them is to delete and start again.
